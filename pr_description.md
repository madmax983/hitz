🚮 Smell: The `hitz-cli` crate contained several instances of `String::push_str(&format!(...))`. This pattern is inefficient because it first allocates a temporary string for the formatted result and then appends it, rather than writing directly into the target string buffer. It also caused `clippy::format_push_string` warnings.
✨ Solution: Replaced the inefficient `push_str(&format!(...))` patterns with the `write!` macro from `std::fmt::Write`. Additionally, resolved related `clippy` warnings regarding `write_with_newline` by swapping `write!(acc, "\n")` to `writeln!(acc)`.
🧼 Benefit: Improves performance by eliminating unnecessary intermediate string allocations during string building in the CLI components. Strict adherence to idiomatic Rust patterns.
🛡️ Verification: Syntax checked via `cargo check -p hitz-cli --bin hitz --target x86_64-pc-windows-msvc` and `cargo clippy -p hitz-cli --target x86_64-pc-windows-msvc`. No logic changed.
